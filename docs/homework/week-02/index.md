# 项目选题
## 最终选题
项目名称：校园二手教材交易平台
## 确定过程
在选题阶段比较了多个候选方向，最终选择校园二手教材交易平台。
| 候选方向 | 主要考虑 | 结论 |
|---|---|---|
| 图书借阅系统 | 业务清晰、实现简单，但交易和消息场景相对有限 | 未选择 |
| 餐厅点餐系统 | 场景容易理解，但单店业务规模偏小 | 未选择 |
| 宠物医院系统 | 角色和流程丰富，但病历、收费和库存模型较复杂 | 未选择 |
| 校园二手教材交易 | 业务明确，具备完整交易链路和多个微服务场景 | 选择 |
