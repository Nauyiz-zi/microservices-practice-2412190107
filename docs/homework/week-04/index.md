## 一、本周目标

本周在 Spring Boot 单体应用中实现校园二手教材交易平台的一条完整业务流程，包括业务模型、Service、REST API、数据库持久化和自动化测试。

核心流程为：

```text
创建教材
  ↓
查询在售教材
  ↓
创建购买订单
  ↓
检查库存和上架状态
  ↓
扣减库存并生成待支付订单
  ↓
查询订单
```

## 二、业务建模
### 设计思路
本周选择教材发布和教材购买作为核心业务流程。
主要实体包括：
- Textbook：表示卖家发布的二手教材。
- TradeOrder：表示买家购买教材形成的订单。

一个卖家可以发布多本教材，一本教材可以产生多个订单，一个订单只关联一本教材。
### 业务规则
订单创建时，Service 必须检查：
1. 教材是否存在；
2. 教材是否处于上架状态；
3. 购买数量是否大于 0；
4. 库存是否充足。

校验失败时不创建订单，也不扣减库存。
